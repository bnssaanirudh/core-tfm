# CoRe-TFM conversation artifact recovery bundle (ESSENTIAL)

This ZIP contains CoRe-TFM research **results, all-in-one notebooks, individual NB35–NB50 notebooks, supporting Python engines and tests, independent audits, manuscript LaTeX and figures, and experiment snapshots** created/shared in this ChatGPT project but not present as identical tracked file contents in the current GitHub branch heads.

Repository checked: https://github.com/bnssaanirudh/core-tfm (4 branches; 524 unique blobs).
Published S2 dataset: https://doi.org/10.5281/zenodo.23507196

## Recommended starting points

- Research data: `03_RESULTS/FINAL_160_CONFIGURATIONS/UNPACKED/` and `CoReTFM_FULL160_Combined_Verified_Evidence.zip`.
- New clean replication: `03_RESULTS/REPLICATION_AND_AUDITS/UNPACKED_SIX_REPLICATIONS/`.
- Original notebooks: `02_NOTEBOOKS_ENGINES_AND_TESTS/NB35_to_NB44/notebooks` and `NB45_to_NB50/notebooks`.
- Standalone stages: `01_NOTEBOOKS_ALL_IN_ONE` includes v2, v3, v5, v6, v7, v8; v4 is in the specialized suite.
- Compilable manuscript: `05_MANUSCRIPTS_AND_SUBMISSION/CURRENT_V1_EDITABLE/`.
- Historical snapshots: `04_HISTORICAL_RUN_SNAPSHOTS/` (only in full bundle).
- Verification and provenance: `00_MANIFESTS/`.

**Not part of GitHub does not mean unpublished:** the S2 evidence has already been deposited on Zenodo. This recovery bundle also contains older files beyond that public deposition. Do not indiscriminately republish all archive contents without checking licenses and accidental extra files.

## Scope and exclusions

Artifacts are deduplicated by exact SHA-256 at source-file level and are checked for ZIP corruption. Two original ZIPs containing an unrelated sepsis PDF were omitted. Source ZIPs that overlap final archives are retained for historical auditability. The package does not assert that all earlier GitHub commits, forks or personal cloud files were searchable.

See `00_MANIFESTS/INDEX.json`, `FILE_MANIFEST_SHA256.csv`, `SOURCE_ARCHIVE_MEMBERS.csv`, and `EXCLUDED_OR_DUPLICATED.json`.
