# Legacy controlled-study exports

The CSV files in this directory supported the earlier 60-task manuscript draft.
They are retained for provenance but are superseded by the checksum-verified
50-seed/100-task results in `../q1_fast_complete_256_v1/controlled_replications/`.

Current manuscript figures are generated by `paper/generate_benchmark_figures.py`
from the final evidence package. Do not use the legacy 60-task files for current
claims or tables.
